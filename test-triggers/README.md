# תכנית טקסט טריגרים לבדיקת עימוד

## מטרה
קבצי טקסט אלה מכריחים הופעת כל הבעיות שדווחו אי פעם במערכת העימוד.
הרצת הבדיקה הגיאוממטרית על קבצים אלה תגלה אם ה-audit תופס את כל הבעיות.

## קבצים

### test-all-triggers.txt
פרק משולב עם כל הטריגרים יחד — בודק אינטראקציות בין בעיות.

### test-trigger-*.txt
פרקים נפרדים — כל אחד מכריח סוג בעיה אחד:

- **test-trigger-widow_orphan.txt** — בדיקת אלמנה ויתום
- **test-trigger-sparse_line.txt** — בדיקת שורה דלילה
- **test-trigger-imbalance.txt** — בדיקת אי-איזון טורים
- **test-trigger-overflow.txt** — בדיקת גלישה
- **test-trigger-page_underfill.txt** — בדיקת עמוד דליל
- **test-trigger-heading_escort.txt** — בדיקת כותרת בתחתית טור
- **test-trigger-settings_conversion.txt** — בדיקת המרות והגדרות
- **test-trigger-unsolvable.txt** — בדיקת מקרים בלתי-פתירים
- **test-trigger-conflicts.txt** — בדיקת קונפליקטים

## עקרונות

1. כל טריגר חוזר במיקומים שונים (תחילת/אמצע/סוף פרק)
2. אין תלות בגופן — כל הטריגרים מבוססי מבנה טקסט
3. כל טריגר מתועד עם הערה איזו בעיה אמורה להיווצר
4. המסמך המשולב בודק אינטראקציות בין בעיות (קונפליקטים)
